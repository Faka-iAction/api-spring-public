# Spring Boot API

The Java / Spring Boot implementation of the FAKA iAction API. API only: it maps onto the shared schema and never runs migrations.

Repository: `Faka-iAction/api-spring-public` (FAKA iAction platform, Spring Boot API component).

## Status

Not started. This backend is planned for after the pilot. Until then the reference implementation is [api-symfony-public](https://github.com/Faka-iAction/api-symfony-public), built against the API contract in [contracts-public](https://github.com/Faka-iAction/contracts-public).

## Visibility

This repository is **public**. Everything in it is visible to anyone. It holds only sanitised content: no secrets, credentials, production infrastructure details, risk thresholds or commercial terms.

## Architecture

This component follows the FAKA iAction master architecture. FAKA iAction is the platform; FAKA iRequest is one vertical on it.
